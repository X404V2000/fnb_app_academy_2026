# fnb_app_academy_2026

## Project Purpose
This project is my practical submission for the FNB App Academy. It is a simple Python application designed to...
- Collect a student's name, subjects, and grades.
- Automatically calculate their average mark.
- Determine and display a final letter grade.

I built this to demonstrate my understanding of core Python concepts like functions, dictionaries, and user input.

## Motivation
I wanted to build this from scratch to solidify my learning and create something I am proud of.
